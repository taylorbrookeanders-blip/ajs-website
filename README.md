# AJ's Gentlemen's Club

Luxury upscale gentlemen's club homepage — cinematic nightlife aesthetic with black/charcoal backgrounds, neon pink and gold accents.

## Stack

- React 19
- Vite 6
- Tailwind CSS 4

## Development

```bash
npm install
npm run dev
```

## Sections

- Hero — cinematic full-viewport intro
- VIP — tiered experience packages
- Entertainers — talent grid
- Food & Drinks — cocktails & chef selections
- Events — calendar & RSVP CTAs
- Instagram — social feed grid
- Contact — hours, location, reservations

## Customize

- `src/components/InstagramSection.tsx` — Instagram URL & handle
- `src/components/ContactSection.tsx` — address, phone, email, map embed
- Replace entertainer placeholder portraits with real photography

## Build

```bash
npm run build
```
